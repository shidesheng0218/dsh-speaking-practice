# 同类竞品调研（2026-10-28）

> 调研目的：给 DSH 英语口语插件（dsh-speaking-practice）定功能优先级与差异化。
> 方法：官方站点 / App Store 元数据（iTunes API，含评分与更新时间）/ GitHub API / 公开页面。
> 限制：本机 web_search 不可用（搜索服务鉴权失败），改用官方页面与商店 API 取证；定价多为“免费下载 + 订阅”，未逐项核验具体金额；用户抱怨未系统采集。

## 0. TL;DR

1. **消费级 AI 口语 App 的护城河不是语音 I/O，而是“内容体系 + 发音评分 + 进度闭环”。** 语音对话已是标配。
2. **DSH 插件生态里“语音输入/朗读”是红海**：至少 10 个插件（voice-call、voice-mode、voice-input、speech-service、dsh-say…），其中 `dsh-voice-call` 已经有免按键通话 + 悬浮窗，和我们 v0.1/v0.3 高度重叠。
3. **但“英语口语教练”是空白**：GitHub 搜 `dsh 口语 / pronunciation / tutor` 没有同类；现有语音插件都停在“听写 + 朗读”，没有场景课程、纠错策略、复盘。
4. 我们的差异化应落在：**本地优先 + 可定制（Markdown/JSON）+ 教练闭环（场景/复盘/复习）+ 与 agent 文件工作流结合（用你的简历/文档出题）**，而不是拼语音链路或内容库规模。
5. 最该补的 3 件事：**客户端浮层（字幕/状态/Stop）**、**发音/跟读反馈（先做 STT diff 版）**、**进度与复习闭环（生词/错题/周报）**。

- 语音输入/朗读已是红海，**没有任何插件做“英语口语教练”**（场景课程、纠错策略、复盘、复习）。

- 客户端 UI 是他们的既有优势、我们的短板；语音链路不是壁垒，**教学闭环 + 可定制 + 本地免费**才是。

## 4. 通用语音助手（ChatGPT Voice / Gemini Live / 豆包 / Kimi）

- 能力：低延迟、可打断、多语言、情感表达；ChatGPT 的 Advanced Voice 与 Gemini Live 都已把“实时语音对话”做成基础能力。
- 对练口语的不足：**不纠错、不评分、不按课程推进、不跟踪进步**；用户会拿它聊天，但不会当“课程”。
- 对我们的启示：语音体验的基线（打断/延迟/自然度）必须达到“通用助手”水平，否则用户会直接去用 ChatGPT 语音；教学层才是我们存在的理由。
- 未验证：本机无法访问 OpenAI/Gemini 的官方页面（JS/网络限制），以上为公开常识，具体能力与价格请以官方为准。

## 6. 值得抄的 UX 模式（按性价比排序）

1. **3 秒开口**：打开即一个“开始练习”按钮 + 默认场景，不要先设置（可栗/ELSA 都这么干）。
2. **实时字幕 + 逐词高亮**：让用户看到自己说了什么、AI 说了什么（voice-call/voice-mode 已证明可行）。
3. **跟读对比**：原句 TTS → 用户复述 → 逐词 diff 高亮（扇贝/可栗的核心体验，我们可用 STT diff 低成本实现）。
4. **目标 → 每日任务地图**：说出目标（“下月面试”）→ 拆成每日任务（Hi Echo/可栗）。
5. **对话中轻反馈 + 课后重报告**：不打断流利度，结束后给逐句纠错（ELSA/Speak）。
6. **进度趋势/连续打卡**：让积累可见（Loora/扇贝）。
7. **角色/口音人设**：面试官、咖啡店员、美音/英音切换（Praktika/可栗）。
8. **场景卡 + 成功标准**：每轮有明确任务（点单成功、说清一个项目），不是无限闲聊。
9. **一键重听/慢速**：听不懂时可回放（我们已有 repeat 雏形，需 UI）。
10. **免费额度 + 订阅转化**：我们是本地免费，可把“无订阅/无云上传”做成卖点，而不是抄付费墙。

## 7. 不该抄 / 做不起的

- **虚拟人视频/口型动画**：成本高、对“开口练习”边际收益低；语音+字幕足够。
- **自研音素级发音评分**：需要强制对齐/音素模型与标注，先做 STT diff + 可选云 API（Azure/讯飞）更划算。
- **万级内容库**：我们用“少量精品场景 + 模型动态生成话题”更符合插件形态。
- **移动端/账号体系/社交**：DSH 桌面场景不需要，反而拖慢。
- **云端订阅模式**：与我们的本地免费定位冲突。

## 8. 我们的定位与差距

**定位**：DSH 里的“本地优先、可定制、带教练闭环”的英语口语插件——把口语练习接进真实工作流（用你的简历练面试、用你的文档练汇报、用雅思素材练 Part 2）。

**已有优势**：本地 STT/TTS（隐私、离线、免费）、免按键循环 + 打断、教练协议（短句/追问/recast）、场景卡、完整+轻量复盘、流式朗读、Markdown/JSON 可改、与 agent 文件工具天然结合。

**差距（按优先级）**：
1. **P0 客户端浮层**：状态（听/想/说）、实时字幕、波形、Stop 按钮。`dsh-voice-call` 已有，我们没有——这是体验分水岭。
2. **P0 发音/跟读反馈**：先做“目标句 vs 转写”的逐词 diff 打分（零成本），再考虑云评测。
3. **P1 进度闭环**：生词本、错题本、周报、连续打卡；把每次复盘自动汇入 `progress.md`。
4. **P1 场景与难度**：6–8 个精品场景 + 难度自适应（按复盘调整 B1/B2）。
5. **P2 口音切换 + 上传材料出题**（简历/文章/会议纪要→练习任务），这是其他 App 难复制的差异点。

## 9. 建议路线（结合调研）

- **v0.4（体验）**：客户端浮层（字幕/状态/Stop/波形）+ 跟读模式（STT diff）+ 场景扩到 4 个（日常/面试/雅思/职场）。
- **v0.5（闭环）**：生词本/错题本/周报 + 难度自适应 + 目标→每日任务。
- **v0.6（差异化）**：上传自己的材料出题（简历/文档）+ 口音切换 + 复盘分享导出。
